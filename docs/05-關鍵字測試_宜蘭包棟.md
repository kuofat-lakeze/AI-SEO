# 05・實際測一組字：「宜蘭包棟」

「我做的東西有沒有效」要拆成三個可以分別量化的問題。拿「宜蘭包棟」當例子，從零預算到有 API 的做法都列出來。

## 先講結論：2026-10-14 的基準快照

用網路搜尋拿同一組問題問了四題（題庫在 `lab/queries/宜蘭包棟.json`），AI 回答引用的來源是：

| 來源 | 性質 | 被引用題數（共 4 題） |
|---|---|---|
| supertaste.tvbs.com.tw（食尚玩家） | 媒體 | 4 |
| gofunit.com | 整理站 | 4 |
| travel.yam.com | 媒體 | 3 |
| housefeel.com.tw | 整理站 | 2 |
| nownews.com | 媒體 | 2 |
| funtime.com.tw、uptogo.com.tw、beauty321.com | 整理站 / 媒體 | 1 到 3 |

被 AI 點名的民宿：水井町、木棉渡假莊園、135會館、梅花參、空島、菁月梧桐、羽楓左岸、彩虹秋千、峇里島漫活、法國小古堡、VillaV、二十輪Villa、水明漾、陳婆婆好宅、灣客棧。

**關鍵發現：沒有任何一題引用民宿自己的官網。** AI 回答「宜蘭包棟」時，依據的是媒體與整理站的文章。所以對一家民宿來說，「AI SEO 有效」的定義是：

1. 民宿名字開始出現在 AI 的回答裡（提及率）
2. AI 回答開始附上民宿官網的連結（引用率）
3. GA4 開始看到從 chatgpt.com、perplexity.ai 來的真人（導流）

這三個數字現在都是 0，就是起點。

## 三層測試，各自怎麼做

### 第一層：被引用（最重要，直接對應關鍵字）

**做法**：固定一組題目，定期拿去問各 AI 平台，記錄回答有沒有提到客戶、有沒有附客戶網址、引用了誰。

**題庫怎麼出**：10 到 30 題，混合三種意圖。`lab/queries/宜蘭包棟.json` 已經有 10 題範例：

- 資訊型：「宜蘭包棟民宿推薦」「羅東冬山包棟 KTV 麻將」
- 比較型：「礁溪包棟 vs 冬山包棟」「宜蘭親子包棟 有溜滑梯球池」
- 交易型：「宜蘭包棟 12人 一晚多少錢」「可以帶寵物 訂房」

**零預算版**：自己開 ChatGPT（開搜尋）、Perplexity、Gemini、Google AI 模式，一題一題問，把回答與引用連結貼進 CSV：

```csv
query_id,answer,citations
q01,"回答全文……","https://a.com/x https://b.com/y"
```

然後：

```bash
python3 lab/citation_check.py lab/queries/宜蘭包棟.json --backend manual --input answers.csv --platform ChatGPT
```

**有 API 版**（可以排程每週自動跑）：

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python3 lab/citation_check.py lab/queries/宜蘭包棟.json --backend anthropic      # Claude + web search
export PERPLEXITY_API_KEY=...
python3 lab/citation_check.py lab/queries/宜蘭包棟.json --backend perplexity     # Perplexity sonar
export OPENAI_API_KEY=...
python3 lab/citation_check.py lab/queries/宜蘭包棟.json --backend openai         # ChatGPT 搜尋
```

每跑一次存一份快照到 `output/citations/宜蘭包棟/`，`report.html` 會把所有快照排成趨勢表。**每週同一天、同一份題庫跑一次**，三個月後就有一條曲線。

**指標**：

- 引用率 = 回答附上客戶網址的題數 ÷ 總題數
- 提及率 = 回答提到客戶品牌的題數 ÷ 總題數
- 聲量佔比 = 客戶被提到的題數 ÷ 所有品牌被提到的題數總和
- 來源結構 = 被引用的網域分布（告訴你該去哪裡「被寫到」）

### 第二層：被讀到（看 log）

優化之後，AI 爬蟲有沒有來抓「宜蘭包棟」對應的那幾頁？

```bash
python3 lab/classify.py access.log --out output/client.json
```

打開 `output/client.json`，看 `aeo_fetch`（ChatGPT-User、Perplexity-User）和 `geo`（OAI-SearchBot、PerplexityBot）的 `top_paths` 有沒有出現 `/宜蘭包棟` 那頁、`/faq`、`/llms.txt`。

有即時抓取紀錄而沒有引用，代表 AI 讀了但覺得不值得引用，問題在內容；連抓都沒抓，問題在 robots、Cloudflare 或根本沒被索引。

### 第三層：被點擊（GA4）

GA4 → 流量獲取 → 工作階段來源，篩 `chatgpt.com`、`perplexity.ai`、`copilot.microsoft.com`、`gemini.google.com`。再看到達網頁是不是包棟那頁、有沒有轉換（訂房表單、LINE 點擊、來電）。

傳統那條線同步看：Search Console 篩查詢字「宜蘭包棟」的曝光與點擊，以及手動查 Google 有沒有出 AI 摘要、摘要裡有沒有客戶。

## 用「宜蘭包棟」的例子，優化要做什麼

從基準快照倒推：

1. **進到被引用的那些文章裡**：食尚玩家、gofunit、FunTime、housefeel 的「宜蘭包棟民宿推薦」文。這是數位公關，不是技術。
2. **讓官網本身變成可引用的來源**：一頁清楚的「包棟資訊」頁，含人數上限、房數、價格區間（平日 / 假日 / 連假）、設施清單（泳池、KTV、麻將、烤肉）、地點與車程，加上 `FAQPage` 與 `LodgingBusiness` 結構化資料。AI 回答的內容形態就是這些欄位，官網沒有就只能引用整理站。
3. **放行 AI 爬蟲、上 llms.txt**：見 `templates/`。
4. **GBP 補齊**：「宜蘭包棟」有地圖意圖，商家檔案的類別、照片、評論回覆都要做。

然後每週跑一次第一層，每月看一次第二、三層。三個數字從 0 開始往上走，就是可以放進提案的成果。

## 常見問題

**AI 每次回答都不一樣，怎麼算？** 所以題數要夠（至少 10 題）、頻率要固定、同一平台多跑幾次取平均。看趨勢，不看單次。

**哪個平台最重要？** 看客戶的客群。台灣消費者目前 ChatGPT 與 Google AI 摘要最多，Perplexity 偏重度使用者。至少追 ChatGPT、Gemini、Perplexity 三家。

**可以直接買工具嗎？** 有，市面上有做 AI 可見度追蹤的 SaaS。這個 lab 的做法是讓你先懂原理、能自己出報告，之後要不要買工具再決定。

## 補充：2026-10-14 三個模型各跑十題的跨平台比較

同一份十題題庫，用三個不同的 Claude 模型各自搭配網路搜尋跑一遍（搜尋索引相同，模型的整理與引用不同）：

| 指標 | 本工作階段模型 | Claude Sonnet | Claude Haiku |
|---|---|---|---|
| 引用率 / 提及率（目標：範例民宿） | 0% / 0% | 0% / 0% | 0% / 0% |
| 引用最多的網域 | 食尚玩家 9 題 | 食尚玩家 7 題 | gofunit、yam 各 5 題 |

三個模型都引用的網域有 9 個（13 個裡的 9 個）：食尚玩家、gofunit、yam、housefeel、FunTime、Airbnb、beauty321、LINE TODAY、uptogo。
三個模型都提到的民宿有 7 間：彩虹秋千、峇里島漫活、水井町、VillaV、二十輪Villa、水明漾、陳婆婆好宅。

**解讀**：來源集合高度一致，表示「宜蘭包棟」的引用來源已經收斂，不是隨機；要被引用就是要進到這幾個來源，或做出比它們更結構化的頁面。品牌提及則分散，三個模型各自挑不同民宿，所以單次測試的品牌結果不可靠，要看多模型、多次的合計。

ChatGPT、Perplexity、Gemini 要各自的 API 金鑰才能跑，`citation_check.py` 已支援四個後端（anthropic、openai、perplexity、gemini），金鑰放進環境變數就能補上。
